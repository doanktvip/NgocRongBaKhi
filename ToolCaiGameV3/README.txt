Chay: bam chuot phai run.bat > Run as administrator, hoac bam dup va chap nhan UAC.

Ho tro:
- PC/Laptop: Windows 10, Windows 11
- VPS/Server: Windows Server 2019
- Windows Server 2012 va cac ban Server khac: chua ho tro

XAMPP, Chrome, Notepad++, JDK 21 va giai nen Teamobi2026 chay song song de rut ngan thoi gian.
Sau khi cac tac vu nay hoan tat: backup htdocs > Web > Database > Game.
Tool co the chay lai; app va cac buoc da hoan tat se duoc kiem tra va bo qua.
Tool can Windows 64-bit va toi thieu 3 GB dung luong trong tren o chua tool.
Chi mot phien setup duoc phep chay tai mot thoi diem.

Luu y:
- Neu may da co XAMPP/Chrome/Notepad++ bat ky phien ban nao, tool khong cai lai.

- XAMPP mac dinh dung tai khoan MySQL root khong mat khau. Neu root co mat khau, dat bien moi truong cap may TEAMOBI_DB_PASSWORD truoc khi chay.
